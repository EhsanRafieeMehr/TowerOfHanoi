# Tower of Hanoi  
A web-based visualization of the classic **Tower of Hanoi** puzzle by [Ehsan Rafiee Mehr](https://github.com/EhsanRafieeMehr).

## 🧩 Project Overview  
This interactive demo allows you to explore the famed recursive problem: moving a stack of disks from one peg to another, subject to the puzzle's rules. The UI features controls for changing the number of disks, pausing/resetting the animation, adjusting speed, and tracking move count.

Visit the live demo: [Tower of Hanoi](https://ehsanrafieemehr.github.io/TowerOfHanoi/)

## Features  
- Select the number of disks (3 through 8)  
- Start, Pause, and Reset controls  
- Adjustable animation speed  
- Visual feedback: current move count, total moves required, and progress percentage  
- Clean, minimal UI for focusing on the algorithm  

## Why It’s Useful  
- **Educational Tool**: Demonstrates recursion, algorithmic efficiency, and state transitions in a visually engaging way  
- **Algorithmic Insight**: Highlights how the number of moves grows (2ⁿ − 1) as disk count increases  
- **Visual & Interactive**: Makes the abstract concept concrete through movement and animation  

## Tech Stack  
- HTML / CSS / JavaScript (no external frameworks required)  
- Lightweight, browser-based, easily deployable via GitHub Pages
